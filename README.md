# School Management System (GR System)

This is a simple School Management System developed in Java using OOP concepts and MySQL database.

## Features

- Add Student
- Show Students
- Attendance Management
- Fee Management
- Result Management
- Student Promotion
- Leaving Certificate
- Full School Report

## Technologies Used

- Java
- JDBC
- MySQL
- OOP Concepts

## OOP Concepts Used

- Classes and Objects
- Inheritance
- Encapsulation
- Method Calling
- Database Connectivity

## Database

Database Name:

```sql
GRSystem
```

## Tables Used

- Students
- Attendance
- Results
- Fees
- Promotions
- LeavingCertificate

## How to Run

1. Create database in MySQL
2. Import tables
3. Add MySQL JDBC Driver
4. Run `GR_System.java`
